# 歡迎使用 oMarker

這是一份可以直接修改的範例文件，花三分鐘看完，就知道怎麼用。開始寫作時，按上方的「＋」新增文件，或直接把這份內容刪掉。

## 1. 切換檢視

畫面底部可以切換四種檢視：

- **即時預覽**（預設）：寫的時候就看到排版結果，游標移到哪一行，那一行就顯示原始碼
- **分割**：左邊寫 Markdown，右邊看預覽，兩邊會跟著捲動
- **原始碼**、**預覽**：只看其中一邊

## 2. 插入東西

- 在空白行輸入 `/`，可以選擇插入表格、圖片、待辦清單、公式、流程圖、日期……
- 選取文字後會出現格式按鈕；也可以用快速鍵：粗體 `Ctrl+B`、斜體 `Ctrl+I`、連結 `Ctrl+K`
- 直接貼上截圖，圖片會存到文件旁邊的 `assets` 資料夾

## 3. 找到所有功能

- **指令面板** `Ctrl+Shift+P`：所有功能都能用名稱搜尋，例如輸入「匯出」「Git」「SSH」
- **快速鍵一覽** `F1`
- 右上角的「⋯」選單：專案、匯出、Git、AI 與終端機、設定

## 4. 資料夾與專案

- 「開啟資料夾」後，左邊會出現檔案樹；`Ctrl+P` 快速開啟檔案，`Ctrl+Shift+F` 搜尋整個資料夾
- 每個資料夾都是一個專案，各自記住開過的分頁；左上角的專案圖示可以切換
- 也能直接編輯 NAS（WebDAV）或 Linux 主機（SSH）上的資料夾

## 5. 存檔、同步與匯出

- 存過的檔案會自動存檔；每次存檔都會留下版本記錄，可以比較與還原
- 資料夾是 Git 儲存庫時，`Ctrl+Shift+G` 打開原始碼控制，一鍵提交與同步到 GitHub
- 可以匯出成 PDF、Word（.docx）、HTML，或用簡報模式播放

## 支援的語法

- [x] 表格、刪除線（~~像這樣~~）、自動連結：https://example.com
- [x] 待辦清單、註腳[^1]、`[[其他文件]]` 連結、`#標籤`
- [x] 數學公式：$E = mc^2$
- [x] 流程圖（Mermaid）

| 功能 | Windows／Linux | macOS |
| --- | --- | --- |
| 指令面板 | `Ctrl+Shift+P` | `⌘⇧P` |
| 快速開啟檔案 | `Ctrl+P` | `⌘P` |
| 存檔 | `Ctrl+S` | `⌘S` |
| 搜尋與取代 | `Ctrl+F` | `⌘F` |

> [!TIP]
> 中文緊接著**粗體**也能正確辨識，不需要在星號前後補空白。

```mermaid
graph LR
  寫作 --> 預覽 --> 匯出
```

[^1]: 註腳會出現在文件最下方。這份文件之後可以從指令面板的「說明：開啟歡迎文件」再打開。
