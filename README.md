# oMarker

中文友善的 Markdown 編輯器：直接在編輯區看到排版結果，也可以左右對照預覽。支援 Markdown、純文字與 JSON，也能開啟 YAML、CSV、HTML 與程式碼檔。

## 下載

**[下載 Windows 版 omarker.exe](https://github.com/omni624562/markdown/releases/download/latest/omarker.exe)**：免安裝，下載後直接執行，之後會自動更新。

## 特色

- **即時預覽**：像 Obsidian 一樣在編輯區直接看到排版
- **中文友善**：兩國用語與錯字檢查、簡體轉繁體、中英文間自動補空格，注音、倉頡組字不受影響
- **匯入匯出**：Word、PDF、HTML，以及複製成格式文字貼到 Word、Outlook
- **桌面版**：資料夾與多專案、Git（GitHub、Azure DevOps／TFS）、工作項目與 Wiki、遠端資料夾、AI 協作
