# oMarker

左邊編輯、右邊預覽，也可以直接在編輯區看到排版結果的網頁編輯器，支援 **Markdown、純文字（.txt）與 JSON**。解析核心用 Rust 撰寫並編譯成 WebAssembly，介面則用 TypeScript，可以自由接上 JS 生態系的套件。

## 功能

**三種文件類型**（依副檔名自動判斷，也可以從左下角狀態列的選單切換）

| 類型 | 編輯器 | 預覽 |
| --- | --- | --- |
| Markdown | 即時預覽、語法上色、選取時浮出的格式按鈕 | GitHub Flavored Markdown（表格、待辦清單、註腳、`> [!NOTE]` 提示區塊） |
| 純文字 | 純文字編輯 | 適合閱讀的排版，保留原本的換行 |
| JSON | 語法上色、錯誤處畫紅色底線 | 可摺疊的樹狀檢視；語法錯誤時以中文說明原因與行、欄位置，可一鍵跳過去，並保留上一次正確的畫面 |

**編輯體驗**

- **即時預覽**（上方的「即時預覽」）：和 Obsidian 一樣，直接在編輯區看到排版後的樣子——標題變大、粗體與連結隱藏符號、待辦變成可以勾選的方塊、表格和公式直接顯示。游標所在的那一行（或選取範圍）會換回原始碼方便修改，離開後再顯示排版；點表格的儲存格就能直接改內容（見下方「表格編輯」），點公式就能編輯它的原始碼，`Ctrl/⌘+點連結` 開啟連結。檔案內容完全不變，注音、倉頡組字也不受影響
- **指令面板**（`Ctrl/⌘+Shift+P`）：輸入關鍵字就能找到所有功能，並顯示對應的快速鍵
- **選取時浮出的格式按鈕**：選取文字後，上方會浮出粗體、斜體、底線、刪除線、螢光標記、行內程式碼、連結，「⋯」裡還有上標、下標、清除格式與插入符號（開啟 AI 協作時還有「AI 處理」）；拖曳選取的過程中不會跳出來擋住文字。想要固定的格式工具列，可以在設定的「外觀」打開
- **底線、螢光標記、上標、下標**（`Ctrl+U`、`Ctrl+Shift+H`）：存成 `<u>…</u>`、`<mark>…</mark>`、`<sup>…</sup>`、`<sub>…</sub>`，GitHub、Obsidian、Typora 也看得懂；預覽、即時預覽與匯出都會顯示。`Ctrl+\` 清除選取範圍的格式
- **插入符號**（`Ctrl+Alt+S`，或空白行的「＋」、右鍵選單）：≤ ≥ ≠ ± × → ✓ ☐ ℃ ‰ α ① 「」…… 等，依數學、箭頭、勾選與圖形、標點、單位與貨幣、希臘字母、編號分類；可以用中文搜尋（打「小於等於」「攝氏」「箭頭」），記得最近用過的符號。按住 Ctrl 點可以連續插入好幾個
- **打字自動轉符號**：輸入 `<=` 變 ≤、`>=` 變 ≥、`!=` 變 ≠、`->` 變 →、`<-` 變 ←、`=>` 變 ⇒、`+-` 變 ±（`<=>`、`<->` 也可以）。程式碼、HTML 註解、網址與數學公式裡不轉換；轉換後馬上按 Backspace 或 `Ctrl+Z` 會還原成原本打的字。可以在設定中關閉
- **右鍵選單**：剪下、複製、貼上、貼上純文字、全選、各種格式、清除格式、插入連結與符號、增加／減少縮排，以及 AI 動作
- **中文標點**：中文句子裡混進半形的 `, . ; : ! ? ( )` 時畫上波浪底線，滑鼠移上去就能改成全形（，。；：！？（））；數字（3.5、10:00）、英文句子、網址與程式碼不會動。和兩國用語共用同一個開關與「修正兩國用語、錯字與標點」指令
- **簡體轉繁體**（「⋯」→「簡體轉繁體（台灣用語）」或指令面板）：連詞彙一起轉成台灣說法（「软件」→「軟體」、「默认」→「預設」、「鼠标」→「滑鼠」），有選取時只轉選取範圍；程式碼、網址與連結位址不轉。貼上的內容看起來是簡體時會主動詢問要不要轉換。詞庫第一次使用時才下載
- **兩國用語與錯字檢查**：中國用語（視頻、默認、軟件、數據庫……）與台灣常見的錯字（即然、再接再勵、按步就班……）畫上波浪底線，滑鼠移上去就能換成台灣的說法，或選「不再提示」。在台灣也有其他意思的詞（例如「質量」「設置」「支持」）用較淡的底線標示並說明什麼情況才要改。「⋯」→「修正兩國用語與錯字」一次修正整份文件中不需要判斷的詞。程式碼、網址與公式不檢查，可以在設定中關閉
- **文件互連**：輸入 `[[` 列出資料夾中的文件，選了就連過去（`[[週報]]`、`[[週報#進度]]`、`[[週報|本週週報]]`，和 Obsidian 的寫法相同）；`Ctrl+點` 開啟，連到還沒有的文件時可以直接建立。大綱面板下方列出「反向連結」：哪些文件連到目前這一份。在檔案樹中改名或搬移時，會詢問要不要一起更新其他文件中的連結（`[[ ]]` 與一般的 Markdown 連結都會更新，改之前的內容記在版本記錄中）
- **標籤**：在文件中寫 `#專案A`、`#KR2`、`#專案/前端` 就是標籤，預覽與即時預覽會顯示成標籤樣式。側邊欄的「標籤」面板依使用次數列出所有標籤，點一下展開有這個標籤的文件；點預覽中的標籤（即時預覽中 `Ctrl+點`）也會跳到這裡
- **待辦總覽**（側邊欄的「待辦總覽」）：把資料夾中所有文件的 `- [ ]` 集中列出，依檔案或截止日排列，可以只看某個 `@負責人`；直接在這裡勾選完成，點文字跳到那一行。待辦中寫 `@小明` 就是負責人，寫 `10/25`、`2026-10-25`、`10月25日` 就是截止日，過了截止日會標成紅色。網頁版列出已開啟分頁中的待辦
- **斜線指令**：在空白行輸入「/」叫出插入選單，繼續打字可以篩選（「/表格」「/todo」「/h2」），按 Enter 插入標題、清單、待辦、表格、程式碼、公式、流程圖、圖片、分隔線、目錄或今天的日期
- **快速輸入日期**：輸入「@今天」「@明天」「@下週一」「@週五」「@月底」，從清單選要插入的寫法：「2026-10-22（星期四）」「2026-10-22」「民國 115 年 10 月 22 日（星期四）」或「10/22」。寫在待辦裡就是截止日
- **插入選單**：游標停在空白行時，左邊會出現「＋」，按下去可以插入標題、清單、待辦、引言、表格、程式碼區塊、數學公式、流程圖、圖片與分隔線；在任何地方按 `Ctrl+Shift+Enter` 也能叫出來。不用 `/` 叫出，因為注音輸入時 `/` 是「ㄥ」
- **中文友善**：`這是**粗體**文字` 這種寫法也能正確辨識；字數統計會把中文字和英文單字分開算；注音輸入選字時不會誤觸快速鍵
- **以詞為單位移動游標**：`Ctrl+←／→` 在中文裡一次移動一個詞（「今天｜討論｜了」），`Ctrl+Backspace／Delete` 刪除一個詞，雙擊選取一個詞；英文維持原本的行為。斷詞使用瀏覽器內建的 `Intl.Segmenter`
- **智慧貼上**：從網頁、Google 文件、Word 複製的內容會轉成 Markdown，保留標題、清單、粗體、連結和表格（腳本、表單等內容一律移除）；按 `Ctrl+Shift+V` 一律貼純文字，從 VS Code 複製的程式碼也照原樣貼上。可以在設定中關閉
- **連結自動完成**：輸入 `](` 時列出資料夾中的檔案（自動轉成相對路徑），輸入 `](#` 時列出目前文件的標題，`](檔案.md#` 則列出那份文件的標題；也可以按 `Ctrl+Space` 叫出建議
- **點預覽中的連結**：`#標題` 會捲到那個位置；相對路徑的文件（桌面版）開成新分頁並跳到標題；網址用預設瀏覽器開啟，不會把編輯器視窗導走
- **大綱拖曳重排章節**：在大綱裡把標題拖到別的位置，整節內容（含子章節）一起搬過去；選取大綱中的標題後按 `Alt+↑／↓` 也能和前後的同級章節交換。一次就能復原
- **專注與打字機模式**（指令面板或設定）：專注模式淡化目前段落以外的文字；打字機模式讓游標所在的行保持在畫面中央。`Ctrl+=`／`Ctrl+-` 調整編輯區字級，`Ctrl+0` 恢復預設
- **匯出 PDF**（右上角「⋯」→「匯出」→「匯出 PDF…」）：可以設定頁首文字、頁尾頁碼（「第 1 頁，共 N 頁」）、封面（標題、副標題與日期）與紙張大小（A4、A5、Letter），會記住上次的選擇。桌面版選好位置後直接存成 PDF，不經過列印對話框；網頁版開啟列印對話框，選「另存為 PDF」。一律用淺色列印，標題不會落在頁尾，長的程式碼會自動換行，表格跨頁時每頁都有標題列
- **簡報模式**（`F5` 從頭播放、`Shift+F5` 從目前這一頁播放，或「⋯」→「簡報模式」）：用一行 `---` 把文件分成一頁一頁，全螢幕播放；沒有分隔線時，每個一級、二級標題各一頁。`→`、空白鍵或點一下換下一頁，`←` 上一頁，`Esc` 結束。公式、流程圖、表格與圖片都照樣顯示，內容太多時自動縮小字級
- **括號自動配對**：`(`、`[`、`"` 與全形「」『』（）《》【】都會自動補上右半邊；先選取文字再打「會把文字包起來。用注音、倉頡打的全形括號也適用
- **表格編輯**：在表格中按 `Tab`／`Shift+Tab` 移到下一格或上一格，最後一格按 `Tab` 會新增一列，`Enter` 新增一列，在空白列按 `Enter` 離開表格。每次移動都會依中文字寬自動對齊；`Shift+Alt+F` 對齊文件中所有表格；指令面板中可插入或刪除欄、列
- **即時預覽中直接編輯表格**：點儲存格就能打字（顯示這一格的 Markdown，例如 `**粗體**`），`Tab`／`Shift+Tab` 移到下一格或上一格（最後一格按 `Tab` 新增一列），`Enter` 移到下一列，`Esc` 存好並離開表格。滑鼠移到表格上時，左上角會出現新增／刪除列與欄、靠左／置中／靠右、「原始碼」按鈕。改完自動依中文字寬對齊；格子裡的 `|` 會自動跳脫，換行存成 `<br>`
- **目錄**（插入選單或指令面板「插入或更新目錄」）：依文件的標題產生可點選的目錄，放在 `<!-- toc -->` 與 `<!-- /toc -->` 之間（GitHub、VS Code 也看得懂）；之後再執行一次、或存檔時會自動更新。只有一個最上層標題時，它會被當成文件名稱，不列進目錄
- **文件範本**（「⋯」→「從範本新增…」）：內建週報、會議記錄、OKR、專案提案；`{{日期}}`、`{{星期}}`、`{{週次}}` 等會換成今天的資料，新分頁的檔名也會帶日期（例如「週報 2026-10-21.md」）。「把目前文件存成範本…」可以加入自己的範本
- **整理文件**（指令面板「整理文件」）：在中文與英文、數字之間補上空格（`用Rust寫了30%` → `用 Rust 寫了 30%`）。程式碼、網址、數學公式、HTML 與 front matter 不會被動到，可以用 `Ctrl+Z` 一次復原。預覽也會用 CSS 的 `text-autospace` 自動加上間距（不改動檔案）
- **數學公式與流程圖**：`$E=mc^2$`、`$$…$$` 用 KaTeX 顯示，` ```mermaid ` 區塊顯示成流程圖（即時預覽中也直接顯示，點一下圖就能編輯原始碼，滑過圖可以放大或複製成圖片）；只有文件裡真的有時才會載入。流程圖預設用輕量的 dagre 排版，需要 ELK 排版時在圖的開頭寫 `config: layout: elk`（這時才會另外下載 ELK）。匯出 HTML 時公式轉成 MathML、流程圖轉成 SVG，不需要網路也能正確顯示
- **設定**（`Ctrl/⌘+,`）：編輯區字級、行號、括號配對、表格自動對齊、自動存檔、兩國用語檢查、圖片自動壓縮、預覽欄寬、內文字型（黑體、明體、楷體、等寬）與行距、大綱放在右邊、公式與流程圖開關、封鎖遠端圖片（不載入文件中網路上的圖片，避免別人得知你何時開啟文件）
- **大綱放在右邊**（設定的「外觀」）：大綱固定顯示在內文右邊，捲動時目前的章節會亮起來，點標題就跳過去；檔案、搜尋、待辦等面板仍在左邊。視窗寬度不到 1100 像素時會回到左邊
- **大綱**：點擊即可跳到對應位置，並標示目前閱讀到的段落
- **捲動同步**：捲動編輯器時預覽會跟著對齊；中間分隔線可以拖曳（或用方向鍵）調整寬度，雙擊恢復一半一半
- **存檔狀態清楚**：分頁上的藍點表示有變更尚未存檔，狀態列的「尚未存檔」按一下就能存檔；草稿會自動保存在瀏覽器
- **自動存檔**（桌面版，預設開啟，可在設定的「編輯」關閉）：停止打字 1.5 秒後、切換分頁時自動存回原檔，注音選字中不會存。檔案被其他程式改過時會暫停自動存檔並提示，按 `Ctrl+S` 逐段比較差異後再存；還沒存成檔案的新文件不會自動存
- **安全存檔**：存檔時先寫到暫存檔再取代原檔，不會因為斷電留下殘缺的檔案；如果檔案在開啟後被其他程式（例如 NAS 同步軟體）改過，會先詢問，可以**逐段比較差異**再決定採用哪個版本
- **檔案**：開啟／儲存／另存新檔（Chrome、Edge 可直接寫回原檔）、拖曳開檔、匯出獨立 HTML、複製 HTML
- **匯入 Word**（「⋯」→「匯入 Word 文件（.docx）…」，或把 .docx 拖進視窗）：轉成 Markdown，保留標題、清單、表格、粗體、斜體、底線、螢光、刪除線、連結與圖片。桌面版在 Word 檔旁邊存成同名的 .md（已經有了就加上「(2)」），圖片存到旁邊的 `assets` 資料夾；網頁版開成新分頁，圖片內嵌在文件裡。EMF 等向量圖無法轉換，會提示
- **匯出 Word**（「⋯」→「匯出」→「匯出成 Word 檔（.docx）」）：標題用 Word 的「標題 1～6」樣式（Word 的導覽窗格與自動目錄都能用），保留表格、清單編號、粗體、螢光、連結、程式碼與圖片；文件內的 `#標題` 連結變成 Word 裡可以點的書籤連結。中文用微軟正黑體
- **複製為格式文字**（`Ctrl+Alt+C`，或「⋯」選單、右鍵選單）：複製排版後的內容，直接貼到 Word、Outlook、Teams、Gmail 時保留標題、表格框線、清單、粗體、連結與程式碼；貼到純文字的地方則是 Markdown 原文
- **多分頁**：同時開啟多份文件，各自保留復原紀錄與捲動位置；關閉有未存檔變更的分頁會先詢問。`Ctrl+Shift+T` 重新開啟剛關閉的分頁，就算關閉時按了「不儲存」，當時的內容也找得回來（網頁版的瀏覽器會搶走這個快速鍵，請用指令面板「重新開啟關閉的分頁」）。重新開啟程式時會還原所有分頁。在分頁上按右鍵可以關閉其他分頁、關閉右側的分頁、關閉已儲存的分頁、複製路徑、在檔案總管中顯示，或固定分頁（固定的分頁排在最左邊，不會被「關閉其他分頁」關掉）
- **快速開啟**（`Ctrl/⌘+P`）：輸入檔名的部分文字就能切換分頁；桌面版還能找到資料夾中的檔案與最近開啟的檔案
- **貼上圖片**：截圖後直接 `Ctrl+V`，或把圖片拖進編輯區。桌面版會把圖片存到文件旁邊的 `assets` 資料夾並插入相對路徑，預覽中也能直接顯示；網頁版可以選擇內嵌在文件裡。寬或高超過 2000 像素的圖片會自動縮小，很大的照片改存成 JPEG（螢幕截圖維持 PNG，文字才清楚），可以在設定中關閉
- **調整圖片大小、放大檢視**：在即時預覽中拖曳圖片右下角調整寬度，寬度記在說明文字後面（`![截圖|400](…)`，和 Obsidian 的寫法相同），預覽、匯出 Word 與複製格式文字都會照這個寬度；點一下圖片放大檢視（再點一下看原始大小），按「編輯原始碼」改圖片的 Markdown
- 新增文件後可以從通知按「復原」找回原本的內容，不需要先回答確認對話框

**介面**

- 簡約的寫作畫面（參考 MarkText）：打開就是一張乾淨的紙，Markdown 預設用即時預覽，其他功能需要時才叫出來
  - **最上面**：已開啟的文件是靠左的分頁，目前這一頁是白底、上緣有一條強調色，和編輯區連成一塊（雙擊可以替還沒存檔的文件改名；分頁很多時用滑鼠滾輪左右捲動）。打開側邊欄時，分頁從編輯區的左緣開始。只有一份還沒存過的空白文件時不顯示分頁，開始打字才出現「未命名.md」。右邊是「原始碼／即時預覽／分割／預覽」切換和「⋯」選單（開啟、存檔、匯出、指令面板、設定等；「匯出」與「AI 與終端機」是子選單，滑鼠移上去或按 `→` 展開。視窗再矮，選單也會留在畫面內，放不下時可以捲動）
  - **Windows 桌面版的標題列**：不用系統的標題列（不會再出現 Windows 強調色的色塊），頂端列兼當標題列。空白處按住可以拖曳視窗（拖到螢幕邊緣會貼齊），連按兩下最大化或還原；右邊是最小化、最大化、關閉按鈕
  - **左上角的側邊欄按鈕**（或 `Ctrl+Shift+O`）：叫出側邊欄，包含切換檔案、大綱（下方有反向連結）、搜尋、待辦總覽、標籤與 Git 面板的圖示列；再按一次收起。設定與主題在右上角「⋯」選單
  - **最下面**：只顯示文件類型和字數（滑鼠移上去可以看字元數與閱讀時間）；有尚未存檔的變更時才顯示存檔狀態，選取文字時顯示選取字數。原始碼與分割模式另外顯示游標所在的行與欄
- 配色參考 MarkText：淺色是白底與柔和的灰，深色接近 One Dark；預覽、即時預覽與匯出的 HTML 用同一套字型（英文用系統字型，中文用思源黑體、蘋方或微軟正黑體）
- 舊版升級後會換成新的簡約版面一次，之後照你自己的選擇（例如改回分割、打開側邊欄）
- 設定依「外觀、編輯、AI 協作、Git、進階」分頁
- 主題可選「跟隨系統／淺色／深色」，載入時不會閃白
- 手機版：編輯與預覽用分頁切換，左上角的側邊欄按鈕打開側邊抽屜（圖示列與面板），觸控按鈕放大
- 無障礙：所有按鈕都有文字標籤與鍵盤操作、焦點外框清楚、支援「減少動態效果」與 Windows 高對比模式

## 版本與更新紀錄

版本號採用語意化版本（`主版號.次版號.修訂號`）：新功能改次版號、修正改修訂號、不相容的改變改主版號。規則與升版方式見 [VERSIONING.md](VERSIONING.md)，每一版改了什麼見 [CHANGELOG.md](CHANGELOG.md)。

## 桌面版（Windows 免安裝）

**[下載最新版 omarker.exe](https://github.com/omni624562/markdown/releases/download/latest/omarker.exe)**（不需登入 GitHub），下載後直接執行，不需要安裝。也可以到 [Releases 頁面](https://github.com/omni624562/markdown/releases/latest)查看更新內容。

- 每次合併到 `main`，CI 都會自動更新這個「最新版」。
- 推送 `v` 開頭的標籤（例如 `v0.2.0`）時，會另外建立該版本的 Release。
- PR 的測試版放在 Actions 的 Artifacts（需登入 GitHub）。

- 介面和網頁版相同，開檔、存檔改用 Windows 原生對話框，`Ctrl+S` 會直接寫回原檔
- **開啟資料夾**：側邊欄的「檔案」會列出資料夾中的 Markdown、純文字與 JSON 檔（略過隱藏檔、`.gitignore` 排除的檔案與 `node_modules`）。可以新增檔案或資料夾、重新命名、移到資源回收筒（可還原）、在檔案總管中顯示；也會記住最近開啟的資料夾，下次啟動自動開回來
- **在資料夾中搜尋與取代**（`Ctrl+Shift+F`）：可區分大小寫、使用正規表示式，點結果直接跳到那一行。按搜尋框左邊的箭頭展開取代欄，「全部取代」會先顯示要改幾個檔案、幾處再確認；取代前的內容會記在每個檔案的版本記錄中，可以還原，有未存檔變更的分頁會略過（正規表示式可以用 `$1` 引用群組）
- **外部修改自動同步**：檔案被其他程式改過時（例如 NAS 同步軟體、另一個編輯器、Claude Code 等 AI 工具），沒有未存檔變更的分頁會自動重新載入（可按「復原」）；有未存檔變更時則提示你逐段比較差異。網路磁碟（`\\NAS\共用` 這類路徑）改用定時檢查
- **版本記錄**（「⋯」→「版本記錄…」）：每次存檔都在本機留一份版本（每個檔案最多 50 份；超過 30 天的會清掉，但至少保留 10 份），覆蓋前檔案上的內容也會一起留下。選一個版本就能逐段比較，決定要採用哪些段落。記錄存在 `%LOCALAPPDATA%\io.github.omni624562.markdown\history`，不會放進你的資料夾
- **網路磁碟最佳化**：`\\NAS\共用` 或對應成磁碟機代號的網路磁碟，讀寫都在背景進行，網路很慢時介面也不會卡住；超過 20 秒沒回應就停止等待，在編輯區上方提示「網路磁碟無法連線」，內容保留在編輯器裡，每 10 秒檢查一次，恢復後提醒你存檔
- **用 GitHub 同步（Git）**：Git 已經內建，不需要另外安裝，也不用輸入指令。
  - **登入**：設定 → Git →「用 GitHub 登入」，在瀏覽器輸入畫面上的代碼授權即可；登入資訊存在 Windows 認證管理員
  - **從 GitHub 開啟儲存庫**：從清單選一個儲存庫，選好放在哪裡，就會下載並開啟
  - **上傳到 GitHub**：把目前開啟的資料夾建立成新的儲存庫（可以選公開或私人）
  - **原始碼控制面板**：顯示分支、變更清單與數量，可以輸入說明後提交、拉取、推送（`Ctrl+Enter` 提交，指令面板也找得到）；檔案樹也會標示修改（M）、新增（U）等狀態
  - **拉取**：能快轉就快轉；兩邊都有新的提交時，改到不同地方會自動合併，改到同一個地方就放棄並維持原樣，不會留下衝突標記
  - **自動同步**：設定 → Git 可以開啟，每 5～60 分鐘提交、拉取、推送一次，出錯就暫停
  - 只支援 HTTPS 的遠端網址（GitHub 用登入的帳號；其他網站沿用 Git 的認證設定），不支援 SSH。內建的 Git 不會執行儲存庫設定裡的外部程式，打開別人給的資料夾也安全
- **WebDAV 遠端資料夾**（檔案面板的「⋯」→「連線到 WebDAV」）：直接開啟 Synology、QNAP、Nextcloud 等 NAS 上的資料夾，不需要先掛載成網路磁碟。可以瀏覽、開啟、存檔、新增、重新命名、刪除（遠端沒有資源回收筒，會先確認）、貼上圖片，預覽也會顯示遠端圖片。每 30 秒檢查已開啟的檔案有沒有被其他電腦改過；存檔時用 ETag 確認，被改過就先詢問，不會蓋掉別人的修改。密碼可以選擇存在 Windows 認證管理員；為了安全，預設只接受 HTTPS，只有區域網路的位址在你確認後才能用 HTTP
- **內嵌終端機**（``Ctrl+` ``，或「⋯」→「AI 與終端機」→「顯示／隱藏終端機」）：在下方開啟 PowerShell，工作目錄是目前開啟的資料夾；可以開好幾個分頁。輸出中的網址按住 `Ctrl` 點一下，就會用預設瀏覽器開啟（例如 Claude Code 開好的 PR 連結）
- **自動更新**：每天檢查一次 GitHub 上的最新版，有新版時詢問，下載並核對數位簽章與檢查碼後替換執行檔（只接受用正式私鑰簽過的版本），重新啟動即完成（設定 → 進階可以關閉，或手動「檢查更新」）。自己編譯的版本不會自動更新
- 可以把 `.md`／`.txt`／`.json` 檔或資料夾拖到 `omarker.exe` 上開啟，或在「開啟檔案」中設定成預設程式。編輯器已經開著時，再開其他檔案會在原本的視窗開成新分頁，不會多開一個視窗
- **最近開啟**（「⋯」→「最近開啟…」）：最近的 10 個檔案與 5 個資料夾
- 原本是 CRLF 換行或有 BOM 的檔案，存檔時會維持原樣；不是 UTF-8 的舊檔案會以 Big5 讀取（存檔時改存 UTF-8，開啟時會提示）
- 需要 Microsoft Edge WebView2 執行階段：Windows 10／11 已內建；若是精簡版系統，可到微軟官網下載安裝
- 草稿與設定存在 `%LOCALAPPDATA%\io.github.omni624562.markdown`

### AI 協作（預設關閉）

在「設定 → AI 協作」（或「⋯」→「AI 與終端機」→「AI 協作設定…」）開啟；第一次偵測到電腦上有安裝 Claude Code 或 Codex 時，也會提示一次。使用你自己安裝並登入的 [Claude Code](https://code.claude.com) 或 Codex，編輯器不會儲存任何帳號或金鑰；AI 提出的修改**一律先逐段標示差異，由你決定是否套用**，接受後也要自己存檔。

- **在終端機啟動 Claude Code／Codex**：「⋯」選單或終端機面板上的按鈕會直接啟動，並自動連上編輯器
- **把選取範圍傳給終端機中的 AI**（`Ctrl+Alt+J`，或選取文字後浮出按鈕中的終端機圖示）：把 `@週報/十月.md#L3-8` 這樣的檔案與行號參照貼到 Claude Code／Codex 的輸入列，接著直接打字問它；沒有選取時傳整份文件。還沒開 AI 時會先啟動，有未存檔的變更會先存檔（AI 讀的是磁碟上的檔案）
- **讓 AI 在終端機執行指令**：AI 可以要求在編輯器的終端機執行指令（例如 `git log`、`pandoc` 轉檔、建置），**每次都會先跳出對話框讓你同意**（預設選在「拒絕」，打字時跳出來也不會誤按），也可以選「這次開啟期間都直接執行」。執行過程顯示在新的終端機分頁，結束代碼與輸出會回覆給 AI；AI 也能讀取終端機分頁的輸出（例如你看到的錯誤訊息）。可以在設定中關閉
- **讓 AI 讀取目前的文件**（編輯器 MCP 伺服器）：AI 可以讀取你正在看的文件、選取範圍與已開啟的分頁，並用 `propose_edit` 提出修改；編輯器顯示差異，你接受或拒絕後，結果會回覆給 AI。伺服器只接受本機連線，而且需要權杖。想在編輯器外的終端機使用，可以在設定中「複製註冊指令」執行一次
- **選取段落快捷動作**（`Ctrl+J` 或在選取範圍按右鍵）：改寫得更精簡、修正錯字、翻譯、摘要，也可以直接輸入指示；動作與提示詞可以在設定中自訂。背後執行 `claude -p`（或 `codex exec`），不給 AI 任何讀寫檔案的權限，完成後顯示用量
- **外部修改逐段標示**：AI 在終端機裡直接改了已開啟的檔案時，標示改了哪些地方，可以逐段還原；連續修改會以第一次修改前的內容為基準
- **GitHub Actions 的 Claude Code**（指令面板「Git：加入 Claude Code 自動校對」）：在 Git 儲存庫建立 `.github/workflows/claude.yml`（使用 [claude-code-action](https://github.com/anthropics/claude-code-action)）。推送到 GitHub 後，開 PR 修改文件時 Claude 會用台灣繁體中文校對、在 PR 上留言建議（不直接改檔案）；在 issue 或 PR 留言寫「@claude 請幫我……」，Claude 會照著做，需要時開 PR。需要在 GitHub 儲存庫設定一次 `CLAUDE_CODE_OAUTH_TOKEN`（建立後可以直接在終端機執行 `claude setup-token` 取得），或在 Claude Code 裡執行 `/install-github-app` 自動設定

編輯器 MCP 伺服器提供的工具：`get_active_document`、`get_selection`、`list_open_documents`、`read_document`、`propose_edit`、`propose_replace_selection`、`run_command`、`list_terminals`、`read_terminal_output`。

自己編譯（需要 Windows 與上面「開發」段落的工具）：

```sh
cd web && npm install && npm run wasm && npm run build
cd ../desktop && cargo build --release   # 產生 desktop/target/release/md-editor.exe
```

開發時可先在 `web/` 執行 `npm run dev`，再於 `desktop/` 執行 `cargo run --no-default-features`，桌面視窗會直接連到開發伺服器、即時更新。

Rust 負責「文件 → HTML」這段需要正確與效能的部分；前端拿到 HTML 後，再交給**預覽外掛**做後續處理。
想加入數學公式（KaTeX）、流程圖（Mermaid）等功能時，只要實作 `PreviewPlugin` 介面，不必改動 Rust：

```ts
// web/src/preview.ts
export interface PreviewPlugin {
  name: string;
  apply(root: HTMLElement): void | Promise<void>;
}
```

可參考 `web/src/plugins/highlight.ts`，然後在 `web/src/main.ts` 的 `new Preview(...)` 加進去即可。
要新增功能時，在 `main.ts` 用 `commands.register(...)` 註冊一個指令，它就會自動出現在指令面板，並套用快速鍵。

安全性：核心一律不輸出原始 HTML（只有成對、不帶屬性的 `<u>`、`<mark>`、`<sup>`、`<sub>`、`<ins>` 與 `<br>` 會換成對應的格式），並會過濾 `javascript:` 等危險連結（`[[ ]]` 連結也一樣）；純文字與 JSON 的內容也都會跳脫，因此預覽可以直接把結果放進 DOM。

## 開發

需要：Rust（stable）、[wasm-pack](https://rustwasm.github.io/wasm-pack/)、Node.js 22 以上。

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-pack

cd web
npm install
npm run wasm   # 編譯 Rust 成 WebAssembly，輸出到 web/pkg（修改 Rust 程式後要重跑）
npm run dev    # 開發伺服器，預設 http://localhost:5173
```

其他指令：

| 指令 | 用途 |
| --- | --- |
| `cargo test --workspace` | 執行 Rust 測試 |
| `npm test`（在 `web/`） | 執行前端單元測試（Node 內建測試框架） |
| `npm run typecheck` | TypeScript 型別檢查 |
| `npm run build` | 建置正式版到 `web/dist`，可以直接部署到任何靜態網站主機 |

## 命令列工具

```sh
cargo run -p md-cli -- html 筆記.md -o 筆記.html   # 轉成完整的 HTML 頁面（.txt、.json 也可以）
cargo run -p md-cli -- html --fragment 筆記.md     # 只輸出 HTML 片段
cargo run -p md-cli -- toc 筆記.md                 # 列出標題大綱
cargo run -p md-cli -- stats 筆記.txt              # 字數統計
cargo run -p md-cli -- fmt 資料.json               # 把 JSON 重新排版（加 -w 直接覆寫檔案）
cargo run -p md-cli -- fmt 筆記.md                 # 依中文字寬對齊文件中所有表格
cargo run -p md-cli -- fmt --spacing -w 筆記.md    # 另外在中文與英文、數字之間補空格，並直接覆寫檔案
```

文件類型依副檔名判斷，也可以用 `--format md|txt|json` 指定。省略檔名時會從標準輸入讀取，例如 `cat 筆記.md | mdtool html`。
