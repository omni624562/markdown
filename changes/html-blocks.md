- 文件裡直接寫的 HTML（例如從 Word、Confluence 轉出來的 `<table>` 修訂紀錄表格、清單、粗體）在預覽、即時預覽和匯出的 HTML／PDF 裡都畫出來了，不再整段不見或顯示原始碼。即時預覽點一下表格就顯示原始碼，可以照常編輯。
- 為了安全，只放行排版用的標籤（表格、清單、段落、文字格式、連結、圖片）；`<script>`、`<iframe>`、`onerror` 之類的事件、`javascript:` 連結一律拿掉，`style` 只留對齊與寬度。
- `<a id="…"></a>` 錨點會保留，目錄的連結跳得到；即時預覽裡這一行淡化顯示。
