- **Claude API 助理**（只在私人電腦使用，預設關閉）：在設定 → AI 協作 → Claude API 助理開啟並輸入自己的 API 金鑰（存在 Windows 認證管理員）後，按 Ctrl+Shift+L 打開右側的助理，可以問目前的文件，或一鍵摘要、改寫、翻譯、審稿、轉成簡報。改寫與翻譯的結果先變成建議卡片，看過差異按「套用」才會改文件；一般回答可以複製或插入到游標處。
- 每個專案要各自允許才能用，新專案預設不允許；Azure DevOps／GitHub 的工作項目、Wiki 與從 Azure DevOps 下載的儲存庫一律不會送出。每個專案第一次送出前會先說明要送什麼、大約多少錢；可以選 Haiku、Sonnet、Opus，並設定每月費用上限，到了上限就停止送出。
