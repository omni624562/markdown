section: 調整

- 新 COMET 專案的自動設定（comet setup）只會在剛用「新專案」建立的資料夾執行一次；其他專案請在終端機執行。
- 保留離線的頁面與圖片有總量上限（500 MB），滿了會提醒你先取消保留一些頁面。
- 很大的檔案（超過 64 MB）不會整個讀進記憶體：在待辦總覽勾選、更新連結時不會修改它們；存檔時如果磁碟上的檔案已經變得這麼大，會先停下來，請改用「另存新檔」。
- 檢查連結時，同時進行的檢查有上限；網路磁碟很慢時，時間到了就先回報已經查到的部分。
- 在檔案總管中顯示只接受存在的檔案或資料夾。
- 在終端機重試 COMET 設定時，安裝路徑裡的彎引號（‘ ’）也會正確處理。
- AI 透過 MCP 不能讀寫 `.git` 資料夾裡的檔案（短檔名、符號連結也一樣）。
- Git 的拉取、推送與下載儲存庫不跟隨轉址到其他網站，登入資訊不會被送到別的網站。
- 文件標題和 oMarker 畫面上的元素同名時（例如標題「Outline Right」），右側欄、工作項目的選單與流程圖不會再抓錯元素。
