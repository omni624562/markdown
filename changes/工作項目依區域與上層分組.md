- **工作項目清單「依區域＋上層項目分組」**：排列方式多一個「依區域＋上層項目分組」（在「依區域分組」後面）。外層和依區域分組一樣一個區域一組（順序、標題、數量、子區域的小字都一樣），組裡再和依上層項目分組一樣排成 Epic → Feature → User Story → Task 的樹，每一層都可以收合。上層在別的區域時（例如 Task 在 Cobalt、它的 User Story 在 IRIS），User Story 淡淡地列在 Cobalt 那一組當上層，Task 只出現在 Cobalt；組的數量只算這一組自己的項目。同一個上層在好幾組出現時各收各的，也不會影響「依上層項目分組」的收合。
- 工作項目清單上方的排列方式選單改成跟著選的那一個的寬度，旁邊的「N 個工作項目」能顯示得多一點；側邊欄很窄時先截短選單的文字，數字不會被擠掉。
