section: 調整

- **指令面板的分類整理**：開著 Git 儲存庫時「Git：提交變更…」不再出現兩次；「Git：拉取」「Git：推送」從「檔案」移到「Git」。Azure DevOps 的指令（工作項目、工作板、Wiki、診斷資料等）原本分散在「Git」「檢視」「檔案」「說明」，現在集中在緊接著「Git」的「Azure DevOps」一區（插入連結的指令仍在「插入」）；關掉 Git 整合時也找得到 Azure DevOps 的指令。拿掉跟別的指令重複的「自訂快速鍵…」（用「說明：快速鍵一覽」或 `F1`，一樣可以改快速鍵）與「顯示搜尋」（用「在資料夾中搜尋」）；之前把它們釘在圖示列或設了快速鍵的，會自動略過，不會出現錯誤。
