section: 修正

- **SSH 第一次連線改用系統的對話框確認主機金鑰**：連到沒看過的主機時，會跳出系統的對話框顯示「第一次連線到 主機:連接埠」、演算法與 SHA256 指紋，確認後才記進 `~/.ssh/known_hosts`（只記那台主機的那個連接埠）；經由跳板主機時，跳板主機和目標主機分開確認。主機金鑰和記錄的不同時一律拒絕連線。主機名稱只接受一般的網域名稱與 IP 位址。
- **跳板主機不會收到目標主機的密碼**：跳板主機只用金鑰或 ssh-agent 登入；需要密碼時，會另外詢問「跳板主機 帳號@主機 的密碼」，選了「記住密碼」才會存起來。
- **修改已儲存的 SSH 連線的跳板主機或金鑰檔時，會重新詢問密碼**：原本存的密碼會從 Windows 認證管理員刪掉，不會用在新的跳板主機上。
- 金鑰檔只接受這台電腦上的完整路徑（例如 `C:\Users\me\.ssh\id_ed25519`），不接受網路路徑；讀不到金鑰檔時的訊息不再顯示檔案內容或解析的細節。
