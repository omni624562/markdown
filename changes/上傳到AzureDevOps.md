section: 新功能

- **上傳到 Azure DevOps**：先在電腦上建立的專案，之後也能放到 Azure DevOps。原始碼控制面板在資料夾還沒有遠端時，除了「上傳到 GitHub」，多了「上傳到 Azure DevOps…」（指令面板與「☰」→「Git」也有）。
  - 選 Azure DevOps 專案，再選「建立新的儲存庫」（名稱預設是資料夾名稱，可以用中文和空白），或「用已經存在的空儲存庫…」（只列出那個專案裡的空儲存庫，例如管理員先幫你建好的）。
  - 會設定好遠端、提交還沒提交的修改，再推送所有的檔案和版本紀錄；之後在原始碼控制面板提交、拉取、推送就好。
  - 資料夾原本已經連到別的遠端時，會先問要不要換掉，選「否」就什麼都不做。
  - 建立新的儲存庫需要專案的「建立儲存庫」權限，個人存取權杖也要勾選 Code 的 Read, write, & manage。
