- **新專案**（桌面版）：「☰」→「專案」最上面多了「新專案…」，起始頁、專案切換器（`Ctrl+Alt+P`）、專案總覽也都有。填專案名稱、選放在哪裡（預設是「文件」資料夾，「瀏覽…」可以換），對話框會寫出要建立的資料夾路徑；一開始可以是空白（只有一份 README.md）或筆記本（README.md、每日筆記、assets 圖片資料夾），可以順便建立 Git 儲存庫、選專案顏色。按「建立並開啟」就切換到新專案、打開 README.md。名稱有 Windows 不能用的字元（`\ / : * ? " < > |`）或保留名稱時馬上提示；資料夾已經存在時不會覆蓋。
